wave 3 · one story, eight engines, real LLM

The Three Little Pigs — v3

Same shared goal — gather materials and reach the brick house before the wolf huffs and puffs — rebuilt in eight rendering engines, narrated live by a real LLM (glm-4-7-flash) through the local proxy. Kid draws the hero, typed words physically spawn props, silly words slapstick-fail, "did you mean…?" helps spelling.

The live model needs the v3 server: python3 v3/server.py → open this same page at localhost:8001. Served from the plain static server (:8000) the v3 pages still run, but in labeled demo mode.

wave 3b · six painted worlds — one vanilla heart
