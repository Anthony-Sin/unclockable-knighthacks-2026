# Fill the Tale — Sticker Sky edition (css-doodle)

One of the seven engine variants of the same mockup. Everything the sky does —
starfields, drifting clouds, rain squiggles, river waves, cave sparkles, meadow
flowers, confetti, mud-splats, splashes, smoke and the glow-dots inside the
firefly jar — is generated by **[css-doodle](https://github.com/css-doodle/css-doodle)**
(v0.40.8), a web component that turns a CSS-like declarative grammar into
generative art. Its signature in this variant: **on every story event the sky
pattern visibly regenerates**, and the whole grammar (not just the seed) is
swapped per journey area.

## Run it

Served from the `mockups/` root like every variant:

```bash
cd mockups && python3 -m http.server 8000
# http://localhost:8000/variants/v6-cssdoodle/
```

`index.html` loads css-doodle from the unpkg CDN and falls back to the vendored
`./css-doodle.min.js` in this folder if the CDN is unreachable. No build step.

## What it demos (beats 0–5)

- **Beat 0 — sticker-builder hero maker.** The kid picks a body shape
  (round / tall / square / pear), an eye style (big / sleepy / starry / wink),
  a hat (antenna / party hat / sprout / star clip) and a color from chunky
  sticker swatches. Pip is assembled live on stage as an SVG figure with a
  white sticker border (a halo of CSS drop-shadows). *Surprise me* randomizes.
- **Beat 1 — Sunset Field.** "The path is blocked — Pip needs a ___ to cross."
  `bridge / log / vine / ladder / tunnel / stepping stones…` spawn real sticker
  props and Pip walks across. A `banana peel` literally slides underfoot → slip.
- **Beat 2 — Rainy Squiggles.** "The hero grabs a ___." `umbrella / big leaf /
  hat / mushroom` flies over Pip's head and shelters the walk. `paper bag`,
  `toast` → soggy droop + drizzle burst.
- **Beat 3 — Wavy River.** "The hero rides the ___ across." `boat` (with a
  generated polka-dot sail!), `duck`, `fish`, and the **paper-craft UNICORN**
  (folded-polygon facets, rideable — Pip visibly mounts and drifts across).
  `toaster` → splashes straight into the water.
- **Beat 4 — Sparkle Cave.** "The hero lights a ___." `lantern / torch /
  firefly jar / candle / flashlight` glows (the jar contains a live mini
  css-doodle of flickering glow-dots), the cave lights up, and Pip carries the
  light across. Silly words → the prop fizzles dead + smoke burst.
- **Beat 5 — Morning Meadow.** "The hero opens the ___." `door` swings open
  with warm light, `key` turns, `cookie jar` pops its lid — then the
  letter-gem `T` payoff plus a recap of every word chosen (and a bonus list of
  the silly ones).

Support character: a **generated constellation critter** — a "sky cat" whose
star-points are procedurally jittered and re-joined every sky re-roll,
twinkling overhead on staggered keyframes.

## Word logic

- Per-beat hardcoded table: `sensible` → prop spawns + success choreography +
  advance; `silly` (curated table + *any* unknown word, which spawns as a
  word-card sticker and does that beat's gag: slip / soggy / splash / fizzle /
  bonk) → retry, no advance; gibberish → gentle "is that a word?" wobble.
- Close-miss spelling help: `bridg` → edit-distance ≤2 match → a
  "Did you mean *bridge*?" chip that accepts it on tap.
- **Watch it play** auto-builds a hero (taps a swatch per row), then types a
  scripted script at kid cadence: `bridge` → `umbrella` → `toaster` (a real
  splash fail!) → `unicorn` → `firefly jar` → `cookie jar`. Fully stoppable.

## How the generative grammar + seed work

Each `<css-doodle>` element holds a grammar: `:doodle { @grid: 15x9 / 100%
100% }` declares the grid; selector functions pick cells (`@random(.4)`,
`@row(9)`, compound `@row(1,2) @random(.34)` = row AND probability), and
`@r`/`@p` (random range / pick) plus `@shape(name)` give each selected cell its
size, color, clip-path, rotation and keyframed motion — all deterministic per
**seed**. Same seed, same sky.

- `el.update()` draws a **fresh seed** → the fail "shock-flip", the success
  bursts and the *Re-roll sky* chip all visibly regenerate the field.
- `el.update(newGrammar)` swaps the entire ruleset → that is how the backdrop
  morphs per area (sunset petals → rotated rain streaks + puddle beans → wave
  rows + generated `@shape(fish)` + rising bubbles → triangle stalactite rows +
  twinkling star-cells + gleaming hypocycloid gems → clover/bud meadow).
- `el.seed` exposes the active seed; the tag under the stage shows
  `area · sky #…`.
- Valid `@shape` names in v0.40.8 (checked against the vendored build):
  circle, triangle, pentagon, hexagon, octagon, star, infinity, heart, bean,
  bicorn, drop, fish, whale, windmill, vase, clover, hypocycloid, bud.

## How the real game would work

The mockup hardcodes the reaction tables and the auto-demo script. In the real
product: a kid-safe on-device classifier (or dictionary service) buckets typed
words; sentence templates ship from the chapter content service; prop actors
map to sprite/skeletal rigs instead of CSS keyframes; and each journey's sky
**seed + grammar id** would be stored with the save file so a child's sky is
reproducible — or re-rollable — across sessions. Fail telemetry (which silly
words kids invent) feeds the gag table so writers can pre-author lines and
bespoke props for the most popular nonsense.
